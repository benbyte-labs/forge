# FORGE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build FORGE, an offline bilingual (HU/EN) futuristic desktop learning app that teaches coding, robotics, physics and CAD through 30-day tracks with hands-on labs, quizzes, a 3D robot simulator, an automatic study-notebook, and a streak/reward motivation system.

**Architecture:** A Tauri 2 desktop shell wraps a React 19 + TypeScript SPA. All motivation, scoring and notebook rules live in a pure, UI-free `src/engine/` layer that is unit-tested first; `src/features/` only renders it. Course content is typed TypeScript modules under `src/content/{hu,en}/`, validated by a parity test so a missing translation or missing note is a compile/test failure, not a runtime blank screen.

**Tech Stack:** Tauri 2 (Rust), React 19, TypeScript 5, Vite 6, Three.js, CodeMirror 6, Pyodide, KaTeX, Zustand, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-28-forge-design.md`

## Global Constraints

- **No runtime network access.** No CDN links, no remote fonts, no telemetry. Every asset ships in the bundle. A `grep` for `https://` in `src/` must only match comments and documentation strings.
- **Node 26 / npm 12** are installed; **Rust 1.98**, **webkit2gtk-4.1**, **libsoup-3.0** are present. Do not add system dependencies.
- **`src/engine/` imports nothing from React, the DOM, Three.js or Tauri.** Its only imports are other engine modules and TypeScript types. Enforced by `engine-purity.test.ts` in Task 5.
- **Every user-visible string goes through i18n.** No literal Hungarian or English text inside `src/features/` or `src/ui/` JSX. Enforced by review, and by the fact that `t()` is the only string source available.
- **Content parity:** `content/hu` and `content/en` expose identical structure — same track ids, same day count, same question count per day, both with a `note`. Enforced by `content.test.ts`.
- **Accessibility floor:** base font size 16px, body text contrast ≥ 4.5:1 against its background in every theme, all animation disabled when `prefers-reduced-motion: reduce` or when the user turns motion off in Settings.
- **TypeScript `strict: true`**, no `any` in `src/engine/`.
- **Dates are local-calendar dates**, stored as `YYYY-MM-DD` strings, never as timestamps. The engine never calls `Date.now()` directly — the current date is always passed in as a parameter, so tests control time.

## Review Focus

These are the failure modes the spec implies but which no feature task naturally exercises. Each line names the input and the behavior a person would expect; the test that pins it is added to the task that owns the code.

1. **System clock moved backwards** (travel, NTP correction, manual change). A `lastActiveDate` in the future must not produce a negative streak, must not silently nuke progress, and must not award a day twice. → Task 6.
2. **App skipped for many days** (a 3-month gap). Streak resets to 0 but XP, level, badges, unlocked themes and notebook entries survive intact, and the SRS queue does not dump 200 overdue items into one day. → Task 6 and Task 9.
3. **Learner's code loops forever or allocates unboundedly** in Code Lab or Robot Lab. The worker must be terminated within its time budget and the UI must stay responsive and explain what happened, rather than freezing the whole window. → Task 16.
4. **Corrupt, truncated or older-schema `state.json`** (interrupted write, hand-edit, version upgrade). The app must start, not white-screen: migrate what it can, back up the unreadable file, and start fresh with a visible notice rather than throwing on boot. → Task 4.
5. **A content day referencing a lab scene, simulation or 3D model that does not exist**, or content authored with a duplicate day number. This must fail the test suite at build time, never render an empty lesson to the learner. → Task 11.

`src/ui/Meter.tsx`:

```tsx
interface MeterProps { value: number; max: number; label: string; tone?: 'accent' | 'ok' | 'warn'; }

export function Meter({ value, max, label, tone = 'accent' }: MeterProps) {
  const clamped = Math.max(0, Math.min(value, max));
  const pct = max === 0 ? 0 : (clamped / max) * 100;
  return (
    <div
      className="meter"
      role="progressbar"
      aria-label={label}
      aria-valuenow={clamped}
      aria-valuemin={0}
      aria-valuemax={max}
    >
      <span className="meter__fill" data-tone={tone} style={{ width: `${pct}%` }} />
    </div>
  );
}
```

`Panel` renders a glass card (`<section className="panel">` with optional `title` and `actions` slots). `Button` supports `variant="primary" | "ghost" | "danger"` and a `loading` state that sets `aria-busy`. `Badge` renders a small pill with `tone`. `Icon` renders inline SVG from a local sprite map — no icon font, no network.

```tsx
export function translate(locale: Locale, key: string, vars?: Record<string, string | number>): string {
  const dict: Record<string, string> = locale === 'hu' ? hu : en;
  const raw = dict[key];
  if (raw === undefined) return key;
  if (!vars) return raw;
  return raw.replace(/\{(\w+)\}/g, (_, name) => String(vars[name] ?? `{${name}}`));
}
```

The provider stores the locale in the Zustand store (wired in Task 4) and exposes `t` bound to the current locale.

- [ ] **Step 4: Implement dates, types and storage**

`migrate` validates field by field with small type guards (`asNumber`, `asString`, `asArrayOf`, `asRecord`), each falling back to the default and flipping `recovered = true`. It never throws. `createStorage()` in Tauri mode writes via the Rust `save_state` command, which writes to `state.json.tmp` and then renames — so an interrupted write cannot truncate the real file.

`src-tauri/src/lib.rs` gains:

```rust
#[tauri::command]
fn load_state(app: tauri::AppHandle) -> Result<Option<String>, String> {
    let path = state_path(&app)?;
    match std::fs::read_to_string(&path) {
        Ok(s) => Ok(Some(s)),
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(None),
        Err(e) => Err(e.to_string()),
    }
}

#[tauri::command]
fn save_state(app: tauri::AppHandle, text: String) -> Result<(), String> {
    let path = state_path(&app)?;
    if let Some(dir) = path.parent() { std::fs::create_dir_all(dir).map_err(|e| e.to_string())?; }
    let tmp = path.with_extension("json.tmp");
    std::fs::write(&tmp, text).map_err(|e| e.to_string())?;
    std::fs::rename(&tmp, &path).map_err(|e| e.to_string())
}

#[tauri::command]
fn export_text(path: String, text: String) -> Result<(), String> {
    std::fs::write(path, text).map_err(|e| e.to_string())
}
```

Register all three in the `invoke_handler`.
